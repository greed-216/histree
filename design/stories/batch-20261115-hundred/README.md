## 文件

- `prepare.py` / `scripts.json`：脚本、分镜、后记、寓意和最终生图提示词。
- `sources/`：从选定 TXT 逐字导出的原文、定位与哈希。
- `existing-ingestion.json`：现有已发布批次及其原文证据。
- `identities.json`：人物稳定 ID 与未绑定原因。
- `image-reviews.json`：逐篇审图及修改记录。
- 各故事子目录的 `atlas-v*.png`：原画与修订版，本地保留，不提交二进制。
- `docs/stories/<slug>.json`：来源、逐格证据、艺术改编与裁切审计。

上传、公开哈希回读、浏览器验收、CI 与部署证据分别保存在 `artifacts/stories-hundred-20261115/`，仅在实际通过后写入发布结果。
