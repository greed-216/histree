# 《资治通鉴》卷285：946年第9—16段

原39—46行连续八段发布并匿名读回。新增8位人物、49个事件、81条参与、8份出处和232条事实引用；复用20位人物与2份出处。新人物李殷、王彦超、白延遇、解里（946年契丹将）、白可久、白铁匮、赫连海龙、王义宗。

覆盖冯晖灵武赢部众信任、市马与先前调任，六月复镇朔方、药元福行营职；定州告警、李守贞皇甫遇张彦泽李殷各职、王白十营赴邢、李彦韬与李守贞态度；陈觉自请宣谕、宋推荐、李家封赏、赴福州冷遇未提入朝；杨刘河决路径；赵延寿归附传言与书信、杜重威致书、赵行实往返约期；李守贞长城北奏报和丁卯回澶；白承福历次入朝战戍迁牧追述、部落犯法、白可久逃契丹授云州；刘郭谋议杀夺、密请迁族、1900人分置、诱入太原、诬五族谋反、围杀共400口、没财褒赏与部众衰弱。

主书七月条内送信经旧史补三月发信七月归书；洛州洺州职地保留异说。主陈未敢说与新史召而不从分别引用。白承福主八月条及新八月、旧汉纪五月执行、旧晋纪八月癸酉奏报分层保留，汉纪帝为刘知远。旧晋纪补白铁匮赫连海龙，旧汉纪补王义宗统余众，不造未名两族。解里谐里近名不硬合。首次整理逐项自查白话、身份时间、计划与执行、奏报与实际日期、原文摘录支持。
