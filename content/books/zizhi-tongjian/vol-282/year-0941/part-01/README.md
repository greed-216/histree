# 《资治通鉴》卷282：941年第1—6段

正月至三月，原86—91行连续整理，已发布并匿名读回。新增8个人物、24个事件、35条参与关系；复用10个人物、2份出处，新增3份出处，共109条事实引用。

## 内容与校核

石敬瑭派张澄率两千兵搜寻并驱逐吐谷浑部众；两千为士兵人数，不是部众人数。王延政修筑建州城、请求设威武军，王延羲实际设置镇安军并授官封王，王延政自行改称镇武军，分别记录。二月壬辰德胜口浮桥不补施工者。

张式劝阻张彦泽杀子、遭射箭和谗言、告病离开、被追捕、李周上报、石敬瑭流放决定、郑元昭索人并转述威胁、交还张式、二月癸未泾州虐杀按阶段分录。《新五代史》补避箭及衍州到邠州护送，《旧五代史》所载汾州路线作为异说，死亡结果由传记印证。杀子与威胁不当作已执行事实，未提前录入次年申诉和追责。未具名儿子与追兵不造主体。

凉州军乱和李文谦闭门自焚分别记录；后蜀军镇长期弊端保留未知年。二月丙辰三名官员加检校官并罢节度使，三月甲戌五名文臣主管军镇分别录；不把知军改成授节度使，不补检校官名号。张讠赞按同书四部丛刊本电子转录固定修订1471325校读为張讚，展示张赞，原文不改；影印字形及纸本待核，同书另一版本不算独立史书确证。

首次整理完成展示文案、人物身份、时间、参与角色与原文引用自查，保留书间异说。旧内容集中回改停在935年，不扩大回改范围。
