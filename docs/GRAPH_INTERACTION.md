# 图谱探索交互

## 行为

- 单击节点：显示详情，将节点平滑移到画布中央，并放大到可读尺寸；搜索结果、关系详情中的人物选择也使用同一聚焦逻辑。
- 双击节点：显示该节点及直接相邻节点组成的子图。可继续双击相邻节点，从完整数据重新展开其关系。
- 探索路径支持回到任一层；“返回上一级”“恢复全图”分别回退一步或恢复当前视图全图。
- 可展开两层关系。人物关系与人物参与事件始终分开；切换视图时清空子图路径。
- 拖动超过6像素后只移动节点或平移视野，不选中、不进入子图；缩放、拖动可中断自动镜头移动。
- Enter选择；Shift+Enter进入关系子图；Esc取消选择。详情中的“进入关系子图”也可用于触屏。
- 全图总览可能缩小以容纳全部节点；选择后恢复可读尺寸。尊重减少动态效果的系统偏好。

- 拖动未选中的张承业后，选中状态仍为李克用，镜头不重新聚焦。
- 人物与事件总览160个节点、207条关系；双击韩建拜相事件后为3个节点、2条参与关系。
- 关系线可选择，详情仍提供史料入口。
