# 全站助手与人物阅读页：本地预览

本轮只做本地预览，不发布应用或历史内容。改动基于已发布的事件阅读 UI。

人物页与事件页共用单栏阅读风格、页内导航和可展开的出处；人物的相关事件保留时间顺序及实际参与角色，重复标题的摘要不再重复显示。没有资料的栏目不显示，加载中的事件不当作完整生平。

全站共用一个史料助手入口。人物、事件、图谱选中条目和关系分别提供上下文；图谱关系通过其实际类型及 UUID 查引用，不能把人物参与连线直接解释成新增因果关系。桌面与手机均使用可拖动的非模态悬浮窗，不压缩正文或图谱；拖动标题栏移动位置，也可聚焦标题栏后用方向键移动。窗口在关闭重开及跨页时保留位置，视口缩小时自动限制在屏幕内。最近讨论可回看，草稿和对话按对象分别保留，内存缓存有上限。

## 启动

使用 Node 24 安装依赖并运行 `pnpm build`，然后执行 `node scripts/run-global-assistant-local.mjs`。默认从当前检出的仓库读取被 Git 忽略的 `apps/api/.env` 和 `.env.migration.local`；独立检出可通过 `HISTREE_LOCAL_CONFIG_ROOT` 指向已配置的仓库。只载入模型和 MySQL 所需配置，不写入客户端。使用本地匿名签名及现有配额校验，不更改线上来源配置。

预览入口为 `http://127.0.0.1:5178/`；本地 API 仅监听 `127.0.0.1:3008`。查看人物、事件后可从页内导航进入图谱，选择节点或关系并提问。当前数据读取已有发布资料，不运行迁移、内容发布或管理员写入操作。

## 验证

- `pnpm build`、`pnpm lint`、`pnpm test`。
- `node scripts/test-global-assistant.mjs`：桌面、390px、320px；正文与参与角色保留、出处展开、草稿恢复、图谱节点/关系、全站入口和上下文隔离。仅问答传输的确定性断言使用模拟回答，不向用户提供该模拟。
- `HISTREE_REAL_ASK_ACCEPTANCE=1 node scripts/accept-global-assistant-local.mjs`：明确运行两次真实模型问题，分别核对人物与指定关系的引用，并将验收输出写入临时目录。普通测试不消耗模型调用。
- 额外检查 768px 平板布局及人物/事件的原有出处导航。
