# 历史图谱阅读与交互

## 两个视图

- 人物关系（默认）：只显示人物与人物之间已记录的关系，保留尚未整理关系的孤立人物。
- 人物与事件：只显示人物、事件和参与关系，连线文字说明参与角色，不混入亲属、政治或事件因果线。事件条目的局部图谱默认打开此视图。
- 两个视图均为自由网络，D3 只计算一次初始布局，之后停止模拟。聚焦、邻居突出和侧栏关系列表均以当前视图的关系为范围。切换视图清除选择与聚焦，重置筛选不会混合两类关系。
- 表格式时间布局不再作为图谱入口展示。

## 操作约定

- 单击节点：原地侧栏显示概述及相关关系；只有“阅读全文与出处”链接会进入条目页。
- 单击连线或其文字：选中关系，突出端点，侧栏提供方向、类型、说明和依据。20 个画布单位的透明线扩大命中范围；关系清单提供另一种选择方式。
- 拖动阈值为 6 个屏幕像素。超过阈值仅移动节点或画布，不改变选择、不导航。节点位置保留在当前视图，选择或打开侧栏不会重新布局。
- 两个视图都允许拖动节点。拖动空白处平移，按钮或 Ctrl/⌘+滚轮缩放，适应全图和恢复布局可恢复视野。
- 键盘 Enter/Space 选择，Esc 取消；关系视图方向键可移动节点。
- 人物聚焦支持一层、两层邻居，范围限于已加载的数据。详情入口原有 `/graph/:id` 仍加载该条目的局部图谱，可明确跳转到全图。
- 搜索突出匹配条目，结果按钮选择详情；人物与事件视图的年份筛选可改变可见范围。隐藏的选中项保留详情并提示。
- 选择关系后按需加载对应 `/evidence/{subject_table}/{id}`；关系 ID 必须携带所属表，避免不同表同 ID 的证据错配。

## 验证

`pnpm test:graph` 覆盖拖动阈值、关系身份、邻居层数、年份稳定排序和边端点几何。浏览器实际操作验证单击不导航、拖动不改变关系选择、连线选择和史料加载。

当前不支持触屏双指缩放；触屏可单指平移并使用缩放按钮。拖动位置不持久化到数据库或跨视图保存。复杂大图仍需通过关系类型与聚焦缩小范围。
