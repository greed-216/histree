# 历史地图绘图工作台

入口：地图页 → 打开绘图工作台（`/map/edit`）。当前版本是个人草稿工具，不写入 Supabase，不改变公开历史内容。

## 使用流程

1. 选择画地点、画路线或画区域，在地图上点击。路线至少两个顶点，区域至少三个，点击完成绘制。
2. 填写名称、适用起止年、依据／出处和定位说明。选择已有要素后可拖动白色顶点。
3. 用查看年份筛选适用要素；取消“显示全部年份”才会启用筛选。
4. 离开页面前保存到本机，并导出 GeoJSON 文件备份。浏览器清理数据、更换设备或域名后不会带走本机草稿。
5. 下一时期可导入上一版文件，调整形状和年份后另存文件；当前浏览器仅保存一份工作草稿。删除和导入都可在当前页面撤销，最多保留 40 步。

参考图可以在侧栏本地对照，图片不会上传。它尚未经过地理配准，不能按图片像素直接推断经纬度。引用他人地图时记录作者、作品、链接、对应年份及修改说明。

## 数据格式

文件为带 Histree 元数据的 GeoJSON FeatureCollection：

- `histree_version: 1`、`title`、`features`
- 每个 Feature 有稳定 `id`，几何只支持 Point、LineString 或单环 Polygon。
- 坐标使用 WGS84 `[经度, 纬度]`，区域首尾自动闭合。
- properties：`name`、`color`（六位十六进制）、`start_year`、`end_year`（含首尾年，无公元 0 年）、`source`、`note`、`status: "draft"`。
- 导入只接受此工具的草稿格式，最多 2 MB、500 个要素、10000 个顶点。可用 GIS 工具处理导出文件，但重新导入前须保留上述元数据及支持的几何结构。

## 已知边界与后续

这一版支持绘制和移动已有顶点，尚不支持加删已有顶点、孔洞、多片疆域、边界吸附、共享边界和自动检查自交。现代底图上的河道、海岸和地名也不能当作历史时期的证据。手绘结果均为待核对草稿。

后续优先按实际整理需求扩展：

1. 参考图控制点配准、透明度和叠加描绘。
2. 为政权、地点、路线增加实体 ID 与多个时间版本；相邻时期沿用未变化的几何，仅修改有依据的变化部分。
3. 经过审核的文件接入 Supabase，与人物、事件和来源关联，再按年份公开展示。

验证数据格式：执行 `pnpm test:map`。
