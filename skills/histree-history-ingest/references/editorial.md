# 史料校核参考

## 按段处理

从本次选定书独立账本的 `active_cursor.next_paragraph` 开始，读取对应卷/篇章段落账本及选定底本。底本与分段按 [资料目录与定位](source-library.md) 的元数据读取，不按书名维护单独流程。核对卷首、篇章及年标题边界；一个年份可能跨卷，纪传体不能强套年次。每段先区分行动、主语、时间、地点、制度与评价，再决定事件或其他资料的整理方式。不能只摘已知人物，也不要求每段新建事件。

- `初` 可追叙前事；`后月馀`、`久之` 不能直接定成年条所在年份。若确年不明，事件 `start_year`、`end_year` 留 `null`，在 `time_original` 与核对说明解释。卷255第8段舒州事件是例子。
- 跨月拆事件，如卷255第5段；干支日保留原样，不自行换算公历。
- 当事人檄文、奏章、回信中的兵数、原因或辩解，写为“某人声称”。卷255第14段朱全忠否认知情是回信中的说法，与第13段围驿叙述并列。
- 区分行动发生日、奏报日与后续诏令日。日历记“甲辰奏本月十五日战”，只能把甲辰用于奏报，不能当战日。不同书的干支、月日各保定位，不为了对齐而自行换算或覆盖。
- 一书只载建议、请求或诏令，不等于事情没有执行。若需判断执行情况，回查相关帝纪和传记；另一书明确执行时，为执行另建独立事实或事件并连接原段。卷280第28段《通鉴》载刘知远“劝尽杀”降兵，旧史卷99汉高祖纪载“帝尽杀之”，应保建议和执行两层，不能把当前书的省略解释成未执行。代称“帝”须先核该纪传传主，保存必要的上下文。
- 疑似 OCR 或转录错误保留在底本快照，记入核对说明，避免用疑字推定地点或数字，如卷255第11段“充州”。可靠异文要有自己的来源与位置。
- 背景时长不能转为开始日期；卷255第10段的“几三百日”只支持到884年陈州解围时已近三百日。

年界须查看相邻原文行。自动账本可能把下一年的帝纪标题或分隔符算入上年；核实后保留原 ID、原字与行号，标 `kind: section_heading` 或 `separator`、`status: excluded_non_body_verified`，事件列表为空，不生成事实引用。在 `boundaries.json` 登记排除原因，正文统计扣除结构项；既有源快照和原始文本不改写。年度完成审计分别统计已发布正文与已核结构项，不把标题误当史事，也不将尚待录入正文标完成。

## 实体和引用

人物关系统一为 `A —关系→ B`，表示“A是B的该关系”。父亲、母亲、兄长、弟弟等写明方向；原文未载长幼的兄弟、姻亲、结义关系保留对称含义，不造长幼。反向阅读不另建副本，性别未知时用子女。新增关系不使用“父子”“母子”“统属”等含糊类型；复用前检查 `content/revisions/`，沿用已校核的端点、类型和稳定key。已应用同人合并的，按 `canonical_key`/UUID复用规范主体，不重新启用已隐藏的重复主体；旧批次key保持档案不改。

检索时回查繁简、别名与异体字，展示名与已有规范一致，原文快照保留底本字形。事件合并核对参与者、时间、地点和行动过程，不凭标题相似合并。相互依赖的多书记载不算独立确证。

人物、事件、参与和关系各自要有 `fact_claim`。摘录必须存在于来源快照，且**确实支持整理后的说法**；结构验证只能检查摘录是否存在。`citation` 至少含书名、卷/篇章/分部和段落ID，编年材料另记原年标题；manifest 记录来源文件 SHA-256。来源的 `edition` 要说明电子版本与校核范围。出处标题与citation中的传主、卷号须回查正文；EPUB原题可能沿用同卷另一传主，不能直接照抄自动章节标签。已发布标签需要勘误时，在 `content/revisions/` 留修订方案与匿名回查，保留原批次及原文快照。

对同名者核实时代、别名和关系后再复用，不因同名直接合并，也不因异体字直接分裂。复用对象写入 `reused-keys.json`，发布预检会查姓名别名、关系端点与已有数据库记录。时间不明或原文未确认的关系不要补成终身盟友、父子或事件因果。地图位置只有史载地名时，坐标为 `null`、`location_precision` 为 `unknown`。

## 当前书覆盖与跨书引文

当前书的连续段落写入 `coverage.json.paragraphs`，其出处列为 `primary_source_key`/`primary_source_keys`；这些兼容字段表示当前批次来源，不表示全站主书。各书独立新增、印证或记录异说时，保留自身引文并通过主体key关联，不要求依附另一书段落。

不要求常规扩大多书补证。若为解决身份、时间、关系、讹字或异说疑问临时引用另一书，创建独立claim和source，在 `coverage.json.supplements` 按下例连接**当前正在录入的书**的段落。例中当前书恰为《通鉴》，换书时使用该书真实段落ID：

```json
{
  "claim_key": "claim_...",
  "source_book": "jiuwudaishi",
  "primary_paragraph_id": "zztj-v255-y0884-p013",
  "subject_key": "event_zztj_255_0884_shangyuan_attack",
  "relation": "adds"
}
```

`relation` 可取 `corroborates`、`adds`、`conflicts`。不要给同一人物或事件另建副本；异说分别保留。
