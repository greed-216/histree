# 《资治通鉴》卷285：945年第11—18段

原16—23行连续8段发布并匿名读回。新增7位人物、46个事件、79条参与、2条亲属关系、5份出处和219条事实引用；复用19位人物及5份出处。新人物王崇文、袜啰、王武（高丽）、郭仁遇、杜昭达、程昭悦、慎温其。

覆盖张彦泽驻恒州；南汉杀刘思潮、林少强、林少良、何昌廷（本段延字异文）与王翷，王调英未到即死；陈州镇安军、南唐宋太后去世；王延政到金陵获羽林、杨思恭被斩、王崇文任永安及宽治；高丽王建早年征战与借袜啰合攻建议、后晋不答及再议、王死王武暂知与后晋册封、郭仁遇出使和实地判断、返回后王武推辞；吴越杜昭达乙卯与阚璠己未分别死、程财结得宠与外任安排、诬告逼供、钱仁俊夺官被囚、诛放百余与慎温其不屈获任。

主南汉四名、新史五人未补第五者；王左右仆射异说并列。高祖在南汉王谋议句为刘岩，高丽外交句为石敬瑭。王建高丽主体与前蜀同名区别，父亲与祖父关系方向核对。王建死亡与消息到达、王武权知与后晋册命分别，死亡纪年未强定；新史迁族946异说承前。吴越诬告与真实行刑分清，诛放为两类概数，姑母未名不造人。宋史补慎后仕钱俶不提前判官官期。电子本与异文待纸本校核，第一次整理已逐项自查简体白话、身份时间与逐字摘录。
