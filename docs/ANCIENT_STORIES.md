# 上古画卷重点史事

前841年以前的四个时代显示20条重点事件：神话时代5条、夏4条、商6条、西周前期5条。右侧预览显示前三条，明确选中时代后下方按顺序显示全部精选。拖动和浏览预览不改变已选时代或年份。

`apps/web/src/data/ancient-stories.json`只保存精选事件稳定ID、时间语境及原文定位，事件标题和正文通过现有公开目录接口一次批量读取。未返回的事件不显示，不以静态备份绕过发布状态。当前只提供精选，尚未分类的其他无年份事件不宣称已全部接入。

这是一条阅读顺序，不是新编年表。不填写事件公元年、不按画面宽度推算年数，也不将篇章位置直接作为时间。现有按年查询和统计保持原有含义。神话时代统一说明传世文献叙事性质；共和元年（前841年）仍为按年画卷的衔接点。

逐条选录、顺序依据、已发布事件与声明ID、逐字引文、固定出处和快照哈希见 [选读校核记录](audits/ancient-stories-20261029.json)。本轮已从生产库只读核对20条事件及其声明的发布状态、主体和来源归属，并核对本地已归档快照哈希及引文字面。既有批次、出处和录入账本不修改。

特别处理：

- 尧考察舜在摄政之前，治水故事保留舜时期语境，禹继位在后；不用本篇所有段落的机械排序替代追叙判断。
- 太甲被放桐宫与迎回还政分两条连续展示；商汤灭夏、牧野之战各只出现一次。
- 周公平乱、还政及成王营洛邑依本篇叙事组织。同属成王时期，不由其展示位置断言营洛邑的绝对年代。
- 厉王监谤保留在西周前期，不把出奔与共和起年的待考换算混进本次展示修复。

验证：`pnpm test:timeline`包含顺序、跨时代去重、已发布数据缺失时省略及原文定位契约；应用发布仍经共享CI、隔离MySQL回归与实际页面验收。
