## TeX是什么

`.tex` 是TeX/LaTeX排版源文件，通常是纯文本，不是扫描图片。此仓库是UTF-8中文正文加LaTeX命令：`\article{...}` 表示篇章标题，`\begin{pinyinscope}` / `\end{pinyinscope}` 是环境标记，`\gezhu{...}` 排版夹注，`\input{...}` 组装文件。

录入时可以直接解析源文件，不必先编译成PDF再抽取。按空行识别原有段落，合并段内机械换行；递归处理夹注时保留注文本和正文插入位置，不能用一个正则删除所有花括号内容。样式定义支持人名、地名等标记，但抽查三部史书的正文命令统计未见这些标记实际使用，不能据此承诺自动识别人名。
