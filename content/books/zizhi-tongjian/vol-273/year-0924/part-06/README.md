# 《资治通鉴》卷273 · 924年 · part-06

连续处理第61—76段至本年末，已发布并完成匿名读回：41个事件、82条人物参与、3条关系、217条事实引用。新增8名人物，复用27名人物；关系新增朱友谦父亲→李令锡、张全义养父→刘皇后，复用朱友谦父亲→朱令德。
