# 100 篇连环画的现代白话改写

原先部分故事省掉了关键人物或转折，只说“解释了”“比较了”，读者难以顺着图文理解；后记又容易直接跳到抽象寓意。本次按连环画的读法，重新编写全部 100 篇的开场、后记和寓意，并修改 242 格图下注文与对应替代文本。

开场先说明人物、处境和行动目标；每格对应一个主要动作，把关键理由说出来；后记接着解释人物的选择和结果，再用日常语言谈读后的体会。历史官名、器物等确需保留的名称，在影响理解处用短句说明。对白是现代白话改写，不冒充古籍逐字引语。

重点修正包括：

- 《鸡鸣狗盗》补回秦王宠姬索裘、收裘后求情的过程。
- 《信陵君救赵》补如姬身份、报恩缘由和兵符的用途，并交代后记所提侯嬴之死。
- 《魏文侯选相》区分魏成子荐人与魏文侯尊师，避免主语含混。
- 《背水一战》说明背水军坚守、奇兵夺营的配合，转述韩信对这支军队的判断。
- 《吴起与士卒》把母亲的忧虑与父亲受恩后死战相接；图下注文与现有照料疮口的画面承接。
- 《张骞出使西域》先讲联合大月氏的任务，再说明未结盟及归国报告的见闻。
- 《勾践尝胆》《晏子赎越石父》去掉当前材料不足以支持的“获释”“救命”等增义。
