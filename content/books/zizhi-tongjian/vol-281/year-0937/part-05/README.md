主书快照逐行回查账本。新旧五代史本纪和列传分别补证；《宋史》卷262李涛传补任职及减轻张氏族刑的上疏。建隆二年年六十四的年龄记载仅用于识别后晋李涛与887年已统兵的吴将不是同一人，不提前建立宋初事件或推算精确生年。安州王晖亦与蜀地同名人分开，用限定名避免不明同人合并。

温韬与三个儿子为三条父亲关系，新史明言延沼与其弟延浚、延衮，另建两条兄长关系。没有从主书列名顺序猜长幼。娄继英儿媳为温延沼女的记载只用于补充阻止杀人的理由，未造匿名女儿姓名。

白奉进夜斩五人、次日争执、帐下杀人、诸军喧乱、卢顺密劝马万、杀数人、三将擒符、方太押送和甲寅敕斩各自分录。符彦饶通谋只是白与卢的指控；《新五代史》认为其被诬为叛乱者，独立保留评价。主书班荆馆与新旧史赤冈不同，保留地点差异，不将双方评价压成一致定论。旧符传章节问题提示和“第二字”疑文不用于新增家世。

刘知远严军纪、处死盗纸钱军士为实际行动，纸钱解释为祭祀用品。高行周主书“东京”、旧史“东都”的留守名称和任官日差异保留。渭州奏事疑滑州字误，保留原字与核对说明。杨军半渡战斩首三千不当作全部伤亡；汜水万余军与旧史破贼千人的口径分开。张从宾是溺死；其党捕后处死与新史娄被杜杀的过程不同，分别引用。

“乃止诛继祚妻子”按宋传补证解释为仅处死张继祚的妻子儿女，其他族人免于牵连，不能误译为停止处死妻子儿女。张全义作为死后功绩被引用，不写成当年亲自求情；李回族曾孙不建立未经族谱证明的直系关系。
