# 《资治通鉴》卷282：941年第22—29段

原107—114行连续整理，九月至十一月及八月追述，已发布并匿名读回。新增8个人物、29个事件、58条参与关系、1条父亲关系、5份出处；复用17个人物，共153条事实引用。

## 内容与校核

滑州九月辛酉为黄河决口奏报日，不补决口发生日。杨彦询乙亥奉派出使与抵帐应答分期；恶子难制是比喻，不能建立安重荣与石敬瑭血缘关系。王亚澄升威武节度使兼中书令、改封长乐王，与此前任官分开。

郭威奉诏劝白承福离开安重荣、许授节度使、厚礼建议及刘知远警告分于十月实际归附；安置、表荐大同节度使及收精骑分别录，表荐不当明确已获授官。安重荣先前檄文中各部同起兵为声称，后来未赴不推已确联盟或背叛。王延羲即皇帝、王延政自称元帅与李敏死亡分开。闽宰相李敏与唐昭宗旧名分开，旧闽尚书及李春燕父亲身份关联另待核。

和凝八月预留空名宣敕建议与皇帝接受不套十一月；十数通与旧史十通分别保留。十一月攻邓州、武延翰奏报、石重贵遣大梁兵赴叶县会合、丁丑统帅及先锋任官分开，新史补明确动用敕令。郭金海族属与陈思让、宋彦筠籍贯按原文引用。十一月庚辰李德珫暂任东京留守与召重贵赴邺，不混十二月正式任命。

邓州守御、安从进退却、癸未花山大败、俘安弘义及数十骑退襄州分期。新史湖阳、李建崇等及野火独立引用；旧史奏报十一月二十七、唐州南、万余敌众保留，不把十二月奏报所列月份当战日。安弘义与旧史安宏义按同次被俘官职对应，父亲关系方向明确，不与次年安弘受合并。单骑与数十骑逃走人数异说保留，未提前写安从进自焚。

首次检查人物身份、展示文案、参与角色、时间、关系方向及逐字出处；原文和旧主体字段保留，未扩大旧内容回改。纸本及异说待核。
