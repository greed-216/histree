# 935年闽人物检索别名

本次仅给既有人物添加王昶、清远公主等检索别名，保规范名、UUID、旧引用和发布档案。

王继鹏在主卷279十月辛巳即位后更名昶，新卷68同证；清远公主是本段追叙所称汉主女王延钧妻，沿917年越主刘岩女嫁王延钧的既有主体与婚姻事件。不将前妻、另一刘氏或新书记作金氏的继室强行合并。

`verify_apply.py` 默认只读，核批次哈希、关联别名claims已公开、当前名字UUID及before/after状态；`--apply` 只更改这两人的aliases字段，随后用匿名权限回查。`aliases.json` 保存计划，`publication.json` 保存实际结果。当前连续发布目标已授权，修订不修改来源原字或服务端环境文件。
