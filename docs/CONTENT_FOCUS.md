# 当前内容方向：五代十国

更新：2026-09-28。用户已选择五代十国作为 Histree 首个持续建设的历史时期。本文件优先于旧路线图中的“春秋战国优先”内容顺序。

## 第一轮交付边界

时代范围已确定；首个试做专题建议为 **“从梁晋争霸到后唐建立（907—923）”**。

- 一个可独立阅读的专题，三段导读：唐亡后的对峙、战争与继承、后唐建立及灭梁。
- 约 6 位核心人物、6—8 个关键事件、必要的关系与逐条出处；数字是控制工作量的上限方向，不为凑数量添加节点。
- 人物候选：朱温、朱友珪、朱友贞、李克用、李存勖、李嗣源。是否独立建条目由专题叙述需要决定。
- 梁、河东李氏的晋、后唐须区分；这里的晋不能与后来的后晋合并。
- 只做支持这条叙述的资料整理；十国专题后续按独立主题展开，不在本轮同时铺开。
- 用户要求先清空全部旧历史内容，包括旧人物、事件、关系、引用、专题及配图，再从五代十国开始。工程测试仅使用隔离的虚构数据，不向业务数据库导入样例。

## 来源起点

已核对在线目录及可访问页面，尚未逐条审核候选人物和事件：

1. [《资治通鉴》目录](https://zh.wikisource.org/wiki/資治通鑑)：卷 266—271 为后梁纪，卷 272 为 923 年后唐纪一。先抽取与专题有关的条目，不整书导入。
2. [《旧五代史》](https://zh.wikisource.org/wiki/舊五代史)：梁书、唐书有关本纪与人物传记，用于对读。
3. [《新五代史》](https://zh.wikisource.org/wiki/新五代史)：作为另一叙述与评价来源；不将史家评价直接变成客观关系标签。
4. [《十国春秋》](https://zh.wikisource.org/wiki/十國春秋)：留作进入具体十国专题时的补充，不作为本轮全面抽取任务。

《资治通鉴》末卷 294 止于 959 年；以后整理宋初与十国后续时，需要另选来源。在线转录须标注电子版本和访问日期，不能冒充已核对纸本；OCR 文本不直接发布。

## 内容生产方式

指定段落 → 保存原文与卷次/纪年定位 → AI 提取候选条目和陈述 → 人工对照审核 → 批量导入草稿 → 发布。

每项候选记录至少包含：稳定标识、名称/别名、简述、时间（或未知）、关联对象、来源、原文片段与定位、审核状态。导入应能预览差异、识别重复、按批次更新，避免把每次修订变成重新填表。

区分“史料记载”“史家评价”“专题作者解释”。没有直接依据的事件先后关系，不自动升级成因果关系。

## 实现约束

- 复用现有人物、事件、专题、图谱与引用页面。
- 补齐本专题必要的别名和称谓；同一个人不因姓名/庙号不同重复建节点。
- 关系需要时段时记录其起止或不确定性，不为整个人物贴永久阵营关系。
- 政权先用一致名称与最小对照清单；遇到实际查询需求再引入独立政权实体，避免现在扩建完整制度模型。
- 优先补批量草稿导入和对照审核，不新增大地图、AI 问答、全史采集或复杂权限。

## 完成标准

读者能从专题读清主要人物、关键事件顺序与政权变化，并打开核心陈述的具体依据；编辑完成一次“材料 → 审核 → 发布 → 修订”的完整流程。

记录第一批内容的人工审核耗时与错误类型，据此决定下一批规模。网站能展示、内容能验证、维护耗时可接受，三项同时满足后再扩展。
