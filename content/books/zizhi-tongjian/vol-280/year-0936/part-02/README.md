# 《资治通鉴》卷280 · 936年第二批

连续第9—12段，原14—17行。四段包含楚汉边政、荆南劝吴即帝、石敬瑭试探移镇和五月朝廷及河东两方议论，拆为30个事件、51条人物参与、145条事实出处。新增10位人物、2条方向明确的亲属关系，复用12位人物；4份新出处快照、1份复用主书快照。

补证《旧五代史》卷48的辛卯移镇、甲午部署和薛文遇独直进言，《新五代史》卷66楚世家补马希广表字与马希范同母弟身份。楚段马希杲、裴仁照、孙德威细事未在本次二十四史检索找到直接独立记载，保主书单证，不伪造补证；后期授官搜索命中不提前变成本年事件。

占验主今年、旧明年两说并列。初、先是与常态未具始年保空年。裴指称、华夫人请赎、楚王来意解释、薛刘桑的预测各归发言者。任命、催行、拒命建议与实际起兵分开；杨彦询被请杀但石保护，不记成被杀。夜庭、赢疾等底本疑字保原字及说明。北京为后唐太原，籍贯不当谈话地点；坐标未核。
