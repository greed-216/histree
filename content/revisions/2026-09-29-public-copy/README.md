# 公开文案清理

将公开书名统一为史书名称与卷次；版本字段保留电子本来源和底本不确定性。删除人物、事件、引用说明中的整理批次、工具身份、文件路径、校验码及待办式措辞，保留史料异文与事实上的不确定性。

- `changes.json`：逐字段修改前后值，保留内部来源记录供维护追踪。
- `apply.sql`：只更新列明的文案字段；原值或目标值匹配才执行，可安全重试。
- `scripts/clean-public-copy.py`：文案规则；907年导入准备步骤自动应用，避免重建后带回内部措辞。
- 引用原文、ID、关系、史料链接和发布状态不变。
- 数据测试验证原始引文逐字不变、补丁可重复运行、预期文案全部匹配。

907年原始发布SQL与审阅日志为历史记录，仍保留当时文字；重新部署历史数据后需应用本修订。最终 content-batch.json 已更新为公开文案。
