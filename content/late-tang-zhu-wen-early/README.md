## 复现与发布

```sh
python3 content/late-tang-zhu-wen-early/build_batch.py
python3 content/late-tang-zhu-wen-early/prepare_import.py
python3 content/late-tang-zhu-wen-early/publish.py
# 完成审核后才执行写入：
python3 content/late-tang-zhu-wen-early/publish.py --apply
```

publish.py 从本地现有服务端环境文件读取凭据，不输出或保存密钥。预检身份冲突、已有同ID内容；先插草稿、核对内容，再按依赖顺序发布；朱温简介采用旧值条件更新。最后用匿名权限逐表读回并验证引用来源可见，记录 publication.json。

REST 多次调用不具备整批SQL事务原子性；中断时检查审计并重跑，发生内容冲突则停止。复用条目不会随本批撤回；朱温回退必须核对审计旧值与后续编辑。不要直接运行通用脚本生成的未过滤回退SQL。
