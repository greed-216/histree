# 世家及跨代传记检查

沿本书连续原文推进；计划组与阅读块、发布单元分开。长卷按君主更替或完整叙事分块阅读，整卷核对后再发布验收，不按人物挑段。

- 为每段确认国家、当前君主及纪年主体；换君、改元、追叙时重新确认承接。“某公二年”先核有出处的元年；并列他国纪年分别计算。保留原纪年和锚点出处，不用整卷时代、世代数或传主寿命替代事件日期。
- 建立或复用人物前核国别、姓名、谥号、爵号、别名和前后世次。同谥不同国、同国重名、父子异名及异体字分别审阅；沿用已核归并及稳定 key，不用继任或同名自动归并。
- 查别名时同时检查已录事件中的参与人物与既有修订，例如同一被杀、继立过程中的斑／般。复用事件后逐条对照规范标题与本段行动，不能仅凭段落 key 的邻近编号认定同事；已存在的参与草稿不直接改为已发布，需另有旧值守卫修订。
- 逐段对照父母、兄弟、婚姻、师生、宾客和任职关系，独立引用证明方向。“某卒，某立”只明载继承时，不补为父子；“后若干世”不生成逐代关系或确切年份。立储、即位、初封、改封分别判断。
- 与本纪、年表及已录其他书的同一行动核对。复用旧事件增加本书出处；同年不同次行动不合并，不为不同记载另建同一事件。身份、谱系、时序异说保留来源限定的声明及待考，不覆盖规范字段。
- 区分传说、行动、计划、人物自述、史家评价及后人注文。谱系资料可直接建立有证据的关系，不为每一代制造占位事件；注文举例不能当作正文当年发生的事。

在统一草稿内保存逐事件时间判断、逐段关系对照及待考说明。按现有工作台、固定出处归档、MySQL、年代侧表、匿名回读和真实网页验收流程发布；原文覆盖、已发事实子集、待考解决分别报告。阅读排版仍由原文结构派生，不改底本、段落 ID 或定位。
