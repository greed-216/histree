# 《资治通鉴》卷285：946年第39—44段

原69—74行连续六段发布并匿名读回。新增8位人物、45个事件、79条参与、4份出处和209条事实引用；复用20位人物、2份出处。新人物关勋、张祚、高勋、王晖（后晋代州刺史）、郭璘、耿崇美、马崇祚、傅住儿。

覆盖李谷密奏、关勋送奏、增兵调粮与消息断绝、桑维翰求见、后方部署、王清夺桥苦战与死亡、杜重威降议索赏骗诺、伏甲迫签降表释甲、赵杜赭袍及任职、恒代易州降与郭璘死、李殷方太降与孙麻马任职、张砺任官谏议、张彦泽先取大梁部署。

旧五代史卷85正文、新五代史卷9及辽史卷76独立补证；旧本纪丁巳密奏据通鉴补文不作独立确证。王清六日战死与己巳奏报、投降十日与壬申得讯分别。王晖同名分档；张砺建议主书南进前及辽传入汴后保留时序疑问。荆州口坐标、刍粮单位未猜。首次整理完成白话、身份日期、同人和逐字摘录自查。
