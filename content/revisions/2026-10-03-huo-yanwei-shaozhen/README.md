# 霍彦威别名补充

依据《资治通鉴》卷二百七十三、同光二年四月庚辰条及《旧五代史》卷三十一，补充霍彦威受赐姓名“李绍真”。

保留已有人物 UUID，追加“霍彥威”“李绍真”“李紹真”别名，供繁简体和赐名检索。未创建新人物，未改动已发布批次的原文快照。

`aliases.json` 记录变更前后的别名、引用事实 ID 和核对理由。`publication.json` 记录线上写入及匿名读取核验结果。

`apply_aliases.py` 默认只读检查；`--apply` 才会写入。执行前检查引用主体及其他人物的姓名、别名冲突，执行后检查公开记录。此修订已经完成发布和核验，无须重复执行。
