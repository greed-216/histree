# 《资治通鉴》卷285：946年第45—50段

原75—80行连续六段发布并匿名读回。新增5位人物、37个事件、76条参与、2条人物关系、4份出处和186条事实引用；复用18位人物和3份出处。新人物薛超、孟承诲、李筠（后晋控鹤指挥使）、乌氏公主、丁氏（楚国夫人）。

覆盖皇甫遇拒率取京与自杀、张彦泽疾进破城、石重贵投火未遂与降表、范质草表及宝印送迎、桑维翰拒逃被拘、孟承诲遇害、京城两日掳掠与杀高勋亲属、李涛见张、帝后迁开封府、夺财看守、乌氏公主告别自缢、表章受控与拒帛酒会、冯玉送宝请求、丁氏被强取。

李涛复用后晋宋初官员主体，不用吴军同名人；控鹤李筠与897已死晚唐李筠分档。降表妻马/冯字形、入京跨夜日期、新史壬申概述及两子职镇称谓分别保留；孙男新妇不作真实亲属。旧桑传密旨贪财说独立补证，死亡留后段。丁母延煦、乌姑母重贵的关系方向明确，未知婚配不猜。首次整理完成白话、身份时间、引用与关系自查。
