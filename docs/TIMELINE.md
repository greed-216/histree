# 时间线与历史长卷

首页与 `/timeline` 共用时间探索组件，`/timeline/scroll` 提供完整艺术长卷。MySQL `timeline_overview` 聚合全库已发布事件，按年代有界读取事件；不把未知年代强定为年份，公元前为负数且没有零年。

长卷使用已固定的 V6 9360×720 图片，图片像素与事件年代坐标一致。原图与生成依据保留在资源目录；不能用旧前端覆盖此功能。它是艺术构图，不是史实图像证据。

## 当前画卷布局

桌面将画卷、刻度与全程导航放在左侧，年度选读放在右侧；760px及以下改为上下布局，年度选读默认显示两条，可展开其余精选。完整事件清单继续在工作区下方阅读。顶部次要浏览操作、分期口径与参考链接使用可展开区域，时间探索页的手机主导航改为单行横向浏览。

工作区使用稳定的高度分配：桌面随屏幕高度在588—768px之间调整，政权带占180px，年度选读填满侧栏；手机主图与导航占514px，政权带占150px，下方选读占140px。政权区按一行大分期加四行主要政权预留完整空间；手机收紧行距，标签保持14px。展开更多政权和选读文本变长时各自在内部滚动，不挤压画卷，也不随内容撑高工作区。其余主图空间留给画卷，完整年份刻度和全程导航保留独立位置；较矮的屏幕通过页面滚动查看下方内容。

画卷、时期带、政权带与年份使用同一无零年的时间坐标。首次测量主图的实际宽高后，初始时间范围适配画幅；后续浏览、缩放及窗口变化不会重置时间范围。画卷按原比例缩放，超出观察窗的纵向部分裁切，可用“画面上下”滑块查看，或“看完整画幅”扩大时间范围恢复全图。画幅完整时上下查看控件仍保留位置并禁用；全景下画面居中，主图区高度保持稳定。画卷与史事模式由用户主动切换，切换不改变视窗和已选年；放大到10年仍保留画卷，底图分辨率不会随放大增加。

大分期来自 `apps/web/src/data/history-scroll.json`；主要政权来自 `apps/web/src/data/timeline-polities.json`，后者独立保存起止年、口径说明与可回查参考，不是全站实体或事件录入批次。南、北朝在180年及以下视窗展开具体政权；桌面与手机初始均显示四行，剩余政权可展开。元从1271年定国号、清从1636年改国号展开，不被1279年或1644年的画卷分界截断。辽采用916年称帝建元、西夏采用1038年称帝建国，来源不同口径保存在说明中。

点击大分期或政权带仅浏览，并为交界留出相邻时间；悬停、拖动、缩放与上下查看画面均不修改已选年或重查清单。抓手支持双向移动：左右拖动浏览年份，放大后上下拖动画卷局部，斜向拖动可同时移动两轴。纵向画幅到边缘即停止，纯纵向拖动不改变时间窗口；完整画幅和史事模式只左右平移。裁切画卷上的触摸手势同样移动画面，区域外及完整画幅的纵向手势仍用于页面滚动。点击图中年份、年份输入与选年滑块才选年。短时期名称保持14px，通过外置标签和连接线对应真实长度的时间条；标签避让和换行不改变时间条的坐标或年数。分界线和标签连接线不拦截指针。参考和口径可在“画卷与分期说明”查看。

秦汉导航列出秦、西汉、新、东汉。秦采用前221年统一至前207年子婴降汉的口径；西汉采用前206年汉王纪年至公元8年的参考表口径，新为9—23年，东汉为25—220年。其他起止口径与23—25年的过渡时期在标签说明中保留，不把这些导航区间视为全站资料录入范围。

`pnpm test:timeline` 检查画卷像素坐标、缩放模式、固定画幅、年份轴与原图哈希。`TIMELINE_TEST_URL=http://127.0.0.1:5173/timeline node scripts/test-timeline-layout.mjs` 通过现有只读API验证桌面和手机四行完整展示、鼠标及触摸双轴拖动、分区尺寸稳定、浏览零事件清单请求与明确选年。截图默认写入 `/private/tmp/histree-timeline-layout/`。
