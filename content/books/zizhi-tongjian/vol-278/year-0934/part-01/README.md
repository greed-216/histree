# 《资治通鉴》卷278 · 934年 · 第一批

连续第1—7正文段（原95—101行）：改元应顺、康义诚兼衔判事、禁军四人换将、三人中书令诏加及冯赟辞受、封三王、徐知诰迁居待吴主、潞王子女出镇召入及疑惧。旧新五代史补证。

引用原快照中跨933至934的通鉴段落，实体复用原source；主段引文仍具体定位934原95—101行。卷统年题为清泰元年，此时闵帝在位改应顺，不提前记从珂即位。冯诏加而未受不当实任，惠明大师与幼澄识同女，旧后文身份仅作识名不提前派生死亡事件。夫人、使臣未名不猜人名；往事及持续动机日期保未定。
