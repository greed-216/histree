# 分块历史底图

## 目的与入口

`/map` 展示可选中地块组成的底图。`/map/edit` 是制作这些底图的工坊。地图版本独立于人物、事件和行为；事件地点与行军路线后续通过叠加层接入。

当前以史图馆 907 年图面作参考，人工概略描绘 12 个主要势力分块。不是精确边界或州县级图层，细小藩镇及周边区域留待补绘。底图在网站上明确标为描绘稿。

## 架构

- `AtlasCanvas`：独立 SVG 地图组件，接收 snapshot、选中 ID、选择回调及可选事件 children。查看和编辑复用同一组件。
- `AtlasDocument`：固定 576 × 390 的绘图画布和多个年份快照。坐标是图面坐标，不是经纬度。
- `AtlasSnapshot`：年份、稳定版本 ID、出处、节点字典和地块列表。
- `AtlasRegion`：稳定地块 ID、显示名称、颜色、有序节点引用、名称位置与依据说明。
- 相邻地块可引用同一边界节点，移动节点会同步修订所有引用它的地块。
- 新年份深复制原版，保留地块 ID，拥有独立节点数据；改新版本不影响旧版本。
- 年份精确匹配，没有底图就显示待绘；不把旧疆域自动当成后来年份的地图。
- 公开图集由仓库 `apps/web/src/data/atlas-907.json` 提供；工坊草稿仅保存在浏览器，不写入 Supabase。

## 绘制流程

1. 从已有年份开始，必要时复制为新的年份版本。
2. 叠加内置 907 年参考图，或选取此版本的本地参考图片。图片按画布范围等比居中显示，坐标按显示位置描绘。参考图片不会上传，不随 JSON 导出，刷新需重新选择。
3. 点击地块并拖动白点修边界，或用方向键微调顶点。新地块依次点击顶点后闭合；接近已有节点时自动复用节点。重绘时替换当前地块的轮廓，原来的邻区仍须核对。
4. 修改分块名称、颜色、依据，使用“移动名称”调整文字位置。
5. 用“预览底图”查看无编辑控制点的效果。所有有效修改自动保存到本机，可撤销最近 40 步。
6. 导出底图 JSON 备份或迁移。导入会替换整个本机图集，可立即撤销。最多 50 个版本、每版 500 个地块和 10000 个节点，导入文件最多 5 MB。
7. 审阅后再将底图版本加入公开图集。当前不提供一键发布，复制到新年份不意味着已核实该年份的疆域。

## 当前边界

单环多边形，尚无自动裁切、合并、孔洞或自交/覆盖检查。重绘或添加分块可能产生重叠、空隙，须人工核对。当前成德使用上层分块展示，尚未从后梁轮廓扣除孔洞，不能将块面积用于疆域面积计算。更精细的版图需要共享边界边段与完整拓扑模型。

下一步可以逐步细分为州或郡的可选地块，再给地块配置政权归属；不需要为此改变事件数据。后续地理事件叠加到图面前，必须建立历史地点与画布坐标的映射，不能把经纬度直接当图面坐标。

旧版点线标注工具留在 `/map/annotations`，本机存储键保持不变。它不再是历史底图的制作入口。

## 来源与验证

史图馆原图与来源说明保留在 `apps/web/public/maps/README.md`。重绘数据的引用信息放在每个 snapshot 和页面页脚，原图版权归原作者。不得把未辨认的图面空白推定为某一政权。

`pnpm test:atlas` 验证版本隔离、精确年份选择、共用节点、数据往返和非法导入；前端 lint/build 与主测试脚本均包含相关检查。手工 UI 检查涵盖点击地块、年份复制、共享边界修订与新块闭合。
