# 时间线与历史长卷

首页与 `/timeline` 共用时间探索组件，`/timeline/scroll` 提供完整艺术长卷。MySQL `timeline_overview` 聚合全库已发布事件，按年代有界读取事件；不把未知年代强定为年份，公元前为负数且没有零年。

长卷在既有 V6 9360×720 图片左侧新增上古章节和年度衔接段，既有文件与哈希保持不变。前841年以前按时代章节展示，之后图片像素与年度刻度保持原比例。原图与生成依据保留在资源目录；不能用旧前端覆盖此功能。它是艺术构图，不是史实图像证据。

## 上古章节与前841年衔接

神话时代、夏、商、西周前期采用独立章节 ID 与画幅宽度，布局位置不编码为公元年，不向按年事件接口传递。五帝段以尧议事、舜耕作交谈、禹勘察疏水为主题，其余以生活与社会场景展开。`?era=five-emperors`、`?era=xia`、`?era=shang`、`?era=western-zhou-early` 可直接进入时代选读；主画卷的时代侧栏与下方正文用于史事选读，不展示画面主题、创作说明或固定史书入口；尚未整理选读时显示简洁空态。后续按时代汇总已发布事实与出处，需要通过真实数据接入，不以画面主题代替史事。

“神话时代”保留原有 `five-emperors` 路由 ID，既有链接继续可用。顶部导航固定为单行横向滚动，按钮不压缩、不折行。春秋、战国导航采用前475年作为共享边界（春秋通常列前770—前476年，战国前475—前221年），参照[国家民委历史沿革](https://www.neac.gov.cn/seac/ztzl/hz/lsyg.shtml)；该分界与前403年的图片接缝分别配置。

上古章节直接并入原有“朝代分期”概览，与前841年后的分期共用同一条带，不另加一排章节按钮。上古区间沿章节布局定位，提示“宽度不代表年数”；年度区间仍保留实际起止年份。点击两类分期均只浏览，不改变已选内容。

前841年为时代章节与年度刻度的转换点，仍处于西周；前403年为新增画面接回旧卷的位置。前841年至前403年共438年，在720px画高下保持约1771.685px宽，前段章节合计1600px仅用于组织阅读。年度输入与滑块从前841年起，不将更早的章节位置格式化成虚构年份。点击时代或年份才更新选中内容；浏览分期、拖动、缩放仍只改变视窗。时代选择通过独立 URL 参数保存，可保留原先选中的年份供返回。已有具体日期及待考记录不因画卷改动而修改。

新增画面与旧卷在山水参考区重叠，保持相同画高和纵横比。生成原图、提示词、构图初稿与校准记录保存在 `design/history-scroll-ancient-v1/`、`design/history-scroll-ancient-v2/`。全卷预览页沿用相同的绘制和分片逻辑。

前841年附近原先两处未对齐的渐变接缝已用 `history-scroll-zhou-repaired-v2.webp` 的连续画面替换，修补参考、生成结果和提示词保存在 `design/history-scroll-seam-fix-20261029/`。`display_offset_pixels` 只校准画面位置，不改年份坐标或章节宽度；裁去春秋图已覆盖的左侧512px时同步补偿位置，修补区右侧仅用32px边缘过渡。源图与旧分片保留，当前分片清单只引用生效画面。

## 视窗分片与渐进加载

`python3 scripts/build-scroll-tiles.py` 从已核验源图生成内容哈希命名的 WebP 分片和 `apps/web/src/data/history-scroll-tiles.json`。分片核心最大宽1560px，边缘带2px重叠以避免缩放缝隙；低清档为半尺寸，高清档保留源尺寸。原始整图仍保留，主画卷不再直接请求整张原图。仅绘制当前视窗可见、且未被后续画面完全覆盖的部分；全卷横向预览也按实际滚动窗口请求。

当前视窗先显示小缩略图与低清分片，视窗稳定350ms且显示密度需要时后台补高清。低清可见片完成后预取左右相邻片，最多同时预取两片；不预取整幅长卷。失败时保留已显示的低清或缩略图，并提供细节重试入口。缓存仅存图片URL与完成状态，浏览器管理图片缓存。

API静态托管对 `timeline-scroll/tiles/` 内带16位内容哈希的WebP返回一年 `immutable` 缓存；HTML、未版本化文件及旧整图保持原有重新校验策略。缓存策略须随后端一起部署才在线上生效；本地Vite预览不证明线上缓存头已经改变。文件字节减少不等同于真实弱网加载耗时，本轮分别记录图片请求范围和文件大小。

## 当前画卷布局

桌面将画卷、刻度与全程导航放在左侧，年度选读放在右侧；760px及以下改为上下布局，年度选读默认显示两条，可展开其余精选；时代选读沿用简洁的史事预览样式，不以画面主题填充。完整事件清单继续在工作区下方阅读。顶部次要浏览操作、分期口径与参考链接使用可展开区域，时间探索页的手机主导航改为单行横向浏览。

工作区使用稳定的高度分配：桌面随屏幕高度在588—768px之间调整，政权带占180px，年度选读填满侧栏；手机主图与导航占514px，政权带占150px，下方选读占140px。政权区按一行大分期加四行主要政权预留完整空间；手机收紧行距，标签保持14px。政权行数较多和选读文本变长时各自在内部滚动，不挤压画卷，也不随内容撑高工作区。其余主图空间留给画卷，完整年份刻度和全程导航保留独立位置；较矮的屏幕通过页面滚动查看下方内容。

前841年起，画卷、时期带、政权带与年份使用同一无零年的时间坐标。首次测量主图的实际宽高后，初始时间范围适配画幅；后续浏览、缩放及窗口变化不会重置时间范围。画卷按原比例缩放，超出观察窗的纵向部分裁切，可用“画面上下”滑块查看，或“看完整画幅”扩大时间范围恢复全图。画幅完整时上下查看控件仍保留位置并禁用；全景下画面居中，主图区高度保持稳定。画卷与史事模式由用户主动切换，切换不改变视窗和已选年；放大到10年仍保留画卷，显示密度提高时补齐源尺寸高清片，超过源尺寸继续放大不会产生额外细节。

大分期来自 `apps/web/src/data/history-scroll.json`；主要政权来自 `apps/web/src/data/timeline-polities.json`，后者独立保存起止年、口径说明与可回查参考，不是全站实体或事件录入批次。战国七雄、十六国各国、南朝四朝、北朝五个政权和五代五朝始终分别展示；桌面与手机均预留约四行的可见高度，当前范围内的全部政权直接加载，可上下滚动查看，无需再次展开更多。首页与完整画卷默认收起各国，只显示朝代分期；“展开国家／收起国家”切换具体政权。展开后当前范围内的各国直接加载，全景也无需再点更多；切换朝代保留展开或收起状态，折叠操作不改变已选年份或浏览时间窗口。底部“另 X 个政权”提示按当前视窗下方尚未完整露出的政权数更新；滚动到底或内容无需滚动时隐藏，提示位置保留，避免挤动画卷。元从1271年定国号、清从1636年改国号展开，不被1279年或1644年的画卷分界截断。辽采用916年称帝建元、西夏采用1038年称帝建国，来源不同口径保存在说明中。

画卷与政权时间带均支持触控板横向滚动，同步平移整个时间窗口；政权区的纵向滚动仍查看其余政权，横向浏览保留当前纵向位置。点击大分期或政权带仅浏览，并为交界留出相邻时间；悬停、拖动、缩放与上下查看画面均不修改已选年或重查清单。抓手支持双向移动：左右拖动浏览年份，放大后上下拖动画卷局部，斜向拖动可同时移动两轴。纵向画幅到边缘即停止，纯纵向拖动不改变时间窗口；完整画幅和史事模式只左右平移。裁切画卷上的触摸手势同样移动画面，区域外及完整画幅的纵向手势仍用于页面滚动。点击图中年份、年份输入与选年滑块才选年。短时期名称保持14px，通过外置标签和连接线对应真实长度的时间条；标签避让和换行不改变时间条的坐标或年数。分界线和标签连接线不拦截指针。参考和口径可在“画卷与分期说明”查看。

秦汉导航列出秦朝、西汉、新、东汉。秦国与秦朝使用一条连续的秦时间条，前221年标出“统一六国”节点并切换配色，前后分别标“秦国”和“秦朝”；秦朝终点采用前207年子婴降汉的口径。西汉采用前206年汉王纪年至公元8年的参考表口径，新为9—23年，东汉为25—220年。其他起止口径与23—25年的过渡时期在标签说明中保留，不把这些导航区间视为全站资料录入范围。

秦汉之后的浏览导航拆为三国（220—280）、两晋十六国（280—420）、南北朝（420—581）。这些区间用于连续浏览，政权可跨越分界：西晋保留自身起点，北魏与十六国各政权仍按原有年份显示，陈也保留至589年的终点；不因导航分段裁短时间条。

`pnpm test:timeline` 检查画卷像素坐标、缩放模式、固定画幅、年份轴与原图哈希。`TIMELINE_TEST_URL=http://127.0.0.1:5173/timeline node scripts/test-timeline-layout.mjs` 通过现有只读API验证桌面和手机四行完整展示、鼠标及触摸双轴拖动、分区尺寸稳定、浏览零事件清单请求与明确选年。截图默认写入 `/private/tmp/histree-timeline-layout/`。

战国七雄的时间条展示前403年起的战国阶段，注明其起点并非各国建国年份；秦国与统一后的秦朝连续展示。十六国按所列纪年参考的具体政权起止口径展示，前赵与成汉的国号更替保留说明；后晋、后汉的公元终点与参考表的不同年界也保留说明。大分期仍是定位入口，政权条始终独立，顺次相接的时间条使用细分隔明确边界。

大分期采用整段底色与加粗标题，作为朝代分期概览；下方政权使用独立标签和按实际年份定位的细时间条。顺次相接及相邻并立的政权优先使用不同颜色；悬停或键盘聚焦名称时，该政权的时间条和连接线同时高亮，不改变年份选择。

五代导航下同时展示十国：吴（杨吴）、前蜀、吴越、楚（马楚）、闽、南汉、荆南（南平）、后蜀、南唐、北汉。沿用原有吴越、南唐条目，补齐其余八国；杨吴与南唐、前蜀与后蜀可在同一行先后显示，并立政权不共用重叠时间条。荆南与南平不重复列国，杨吴、马楚也与三国吴、战国楚区分。五代导航保留907—960年的连续分期；杨吴从902年起，北汉至979年止，各国的自身区间不被唐、宋导航边界截断。

十国起止口径依据教育部《中国历代纪年表》和香港教育局《前蜀王建墓文物与武人政权》所附表（PDF第6—7页）。楚采用907—951年，保留香港教育局表927年起点的说明；南汉采用917—971年，荆南采用924—963年，另在各自说明中保留教育部表907年起点、960年终点的不同口径。
