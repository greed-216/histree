# 时间图

入口 `/timeline`，可用 `?year=900` 分享选中年份。公元前年份使用负数，时间轴跳过公元 0 年。

- 全景以事件起始年聚合；河流厚度与光点只表达已录入事件数量，不代表历史重要性、人口或国力。长时间范围最多约 100 个分段，默认窗口最多约 100 年，局部放大最小约 10 年。
- 当年清单包含起始年不晚于所选年且结束年不早于所选年的事件。未填结束年视为起始年当年；未知起始年不进入当年清单，仅计入待补充数量。
- 统计使用 `timeline_overview()`，只返回年度数量和整体范围；清单每次读取 20 条及一条探测记录，稳定按起始年和 UUID 排序。API 与静态 Supabase 直连均使用显式 published 筛选。
- 既有事件详情负责人物、关系和出处阅读。此版本仅展示真实已发布资料，没有推演分支或生成的历史内容。

## 发布与验证

上线先执行 `supabase/migrations/20261001090000_timeline_overview.sql`，再发布 API 和前端。静态 Pages 不依赖 API，但同样需要此 RPC。迁移只增加只读统计函数，不修改历史资料。

`pnpm test:timeline` 验证完整迁移链及超过 1,000 条数据、公元前、跨年范围、未知日期、匿名和已登录用户的草稿隔离。API 单测验证参数和分页。`pnpm test` 包含这些检查。

`VITE_API_URL='' pnpm --filter web dev --host 127.0.0.1 --port 5174` 后运行 `node scripts/test-timeline-browser.mjs` 验证浏览器。该脚本只读本地环境配置和线上已发布事件，以真实日期构造尚未部署的统计 RPC 响应，事件清单使用线上查询；另用小型测试数据验证公元前 1 年到公元 1 年的边界。截图写入 `/tmp`。这项验证不代表线上 RPC 已部署。

## 时间图交互

光标在图上移动时仅预览年度提要与虚线标记，不修改地址、固定年份或下方事件清单。点击才固定年份并加载清单；移开光标恢复固定年份的提要。触摸设备保留点击和滑块操作；放大时固定时间窗口。时间图内年份参数变化保留页面滚动位置，进入详情页仍回到顶部，返回时通过统计与事件缓存恢复位置。

本地或线上回归：`TIMELINE_TEST_URL=https://greed-216.github.io/histree/timeline node scripts/test-timeline-interaction.mjs`。覆盖年度提要、悬停零请求、点击固定、放大范围稳定、年份切换不回顶、详情跳转与返回，以及移动端布局。

年度提要随全景一次返回，每年最多三个已发布事件标题，优先使用已有 impact_level，缺失时优先选择包含政权变化关键词的标题，再按稳定 UUID 排序。这是事件选读而非完整年史或生成事实。迁移 `20261003090000_timeline_highlights.sql` 增补只读统计函数，旧客户端兼容。渲染使用 D3 area/line 与 curveMonotoneX 保持曲线平滑和零记录段，不引入新的图表依赖。

## 长卷视窗

主图横向拖动和触控板横向滚动用于平移；前一段、后一段按窗口宽度的 80% 翻卷。两端限制在当前资料范围，禁用越界按钮。底部概览始终展示全部资料范围，框表示当前可见窗口，圆点表示固定年份；点击概览定位，拖动框平移，拖动两端调整范围。卷首、卷尾、回到已选年份和输入年份提供快速定位，键盘可用这些按钮和固定年份滑块。

默认展示最多约 100 年；全程、缩小、放大控制窗口，最小约 10 年。间距按连续年份计算，缺少记录的年份不被压缩。拖动超过 5px 后不触发点击选年；指针取消也不触发选年。触摸设备纵向手势留给页面阅读。浏览、翻卷、缩放不请求下方事件列表，点击选年才加载。

主图保持最多约 100 个统计分段，概览每个有记录的起始年份绘制一条密度刻度，不加载完整事件正文。河流与光点是数据视觉，尚未加入时代山水插画或虚构史实。

`node scripts/test-timeline-viewport.mjs` 覆盖五千年范围、连续公元前后年份、卷首卷尾限制、窗口宽度保持和单一年份边界。浏览器另验证主图平移、概览移动和两端调整，以及手机宽度下无水平溢出。
