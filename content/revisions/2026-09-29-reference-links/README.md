# 参考资料仓库链接

参考史籍全文、分卷和PDF已归档到本仓库resources目录。网站19个来源链接指向固定提交中的对应文件。

- 原有维基文库引文链接到已保存的同版文本，不换用另一版PDF。
- 《资治通鉴》907年条所据文本链接到同版卷266；逐条检查了全部579条文本来源引文均存在于目标文件。
- 新旧五代史PDF与原下载文件保持相同内容，页码继续有效。
- 吴越备史、蜀梼杌指向所据分卷，保留原页标。
- `links.json` 保存旧链接、新链接、归档提交、文件校验值。
- `apply.sql` 只更新来源URL，保留书名、版本说明、引用原文、对象ID和关联。
- 导入编译器对已归档来源复用固定链接，避免重建后退回第三方站点。

原始采集来源与版本信息继续保存在各来源清单中。更新资料时应创建新版本并复核受影响引文，不修改固定链接所指版本。
