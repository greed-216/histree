# 《资治通鉴》卷264 天复三年 第17–24段校核

- 原TXT第22–29行连续处理。第17–19段沿用上一批已归档的《通鉴》段落快照，第20–24段用本批新导出的原TXT快照；出处 URL 均指固定 Git 提交。
- 第17段成汭出兵、李珽进谏与未被采纳分别记。巨舰“三年而成”只作起止年不明的追叙。旧、新《五代史》两篇李珽传均记此策与败亡，但不把两者当独立统计确证。
- 第18段王建攻秦陇、遣韦庄入贡并与朱全忠往还、星宿山阅马分录。此前十年买马未倒推确年，史载马数保留为记数。
- 第19段“李存审”复用站内已有“符存审”主体及其别名，避免同人重建。契苾让据振武由“先是”引出，确年未载；五月夺回振武与李克用责罚诸将另录。
- 第20段许德勋、欧阳思陷江陵与李神福遣将于君山败成汭是两件事；庚戌、壬子不混。新旧《五代史》称成汭自沈或溺死，《通鉴》称赴水死，原文并列。
- 第21段雷彦威常年焚掠是史书概述，未填为903年一次行动。第23段六千六百为崔胤奏请人数，不等于实际募足。
- 第24段《通鉴》电子底本作“武宁李度使”，疑有讹字，故仅记朱全忠表荐武宁使职；《旧五代史》朱友恭传作“天复中，为武宁军留后”，官名异文待纸本核。
- 卷264的903年尚余第25–54段，全年未完成。
