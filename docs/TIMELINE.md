# 时间线与历史长卷

首页与 `/timeline` 共用时间探索组件，`/timeline/scroll` 提供完整艺术长卷。MySQL `timeline_overview` 聚合全库已发布事件，按年代有界读取事件；不把未知年代强定为年份，公元前为负数且没有零年。

长卷使用已固定的 V6 9360×720 图片，图片像素与事件年代坐标一致。原图与生成依据保留在资源目录；不能用旧前端覆盖此功能。它是艺术构图，不是史实图像证据。

`pnpm test:timeline` 核对图片哈希、原始拼接像素、坐标、缩放／拖动与公元前后连续性。原生统计、超千条事件与草稿隔离由 `pnpm test:mysql` 验证，发布脚本验证实际图片 SHA-256。
