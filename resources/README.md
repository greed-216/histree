## 来源与版本

- 选定工作文本：用户提供的维基文库EPUB快照转换TXT，原EPUB及其来源元数据在backup，具体文字仍待纸本校核。
- 二十四史PDF备份：[LeungGeorge/grimoire-kindle](https://github.com/LeungGeorge/grimoire-kindle)，原始提交及文件校验见[来源目录](catalog/twenty-four-histories.json)。这些文件为电子排印本，尚未核定纸本底本。
- 补充史籍：[汉籍仓库 Kanripo](https://github.com/kanripo)。保留各书的原有版本说明及页标；来源提交见[目录](catalog/kanripo.json)。
- 《资治通鉴》全文底本未详；分卷仅便于定位，未改写正文。[分卷索引](catalog/tongjian-volumes.json)。
- 维基文库、Project Gutenberg 的补充文本及归属信息保留在[补充资料](originals/supplements/)中；《五代会要》《十国春秋》的该组副本未齐卷，完整阅读请用上方汉籍仓库版本。
- 网站早期引用的维基文库文本保存在[引用快照](../content/later-liang-907-923/sources/)，与二十四史PDF为不同版本，不互换引用。
