# 表格、世表与年表

先识别本篇采用的结构，再整理事实；不同表、不同区块可采用不同表头。按选定分段原文读取，保留 tabs、空列、跨行和题注。现代编辑添加的公元年只作对照依据，不能冒充古文原有纪年。

- **列位**：每行逐格对应实际表头。少一格、多一格、合并格、栏中换纪年都要回查相邻行及必要底本；不能删除空列后用固定下标猜国家、人物或年号。无法还原的格保留待考，不借相邻列补造。
- **时间**：初封、增封、继承、处分分别核时间。同一物理行可记多个年号、追叙和终年。“侯某元年”是该侯在位计数，须先找到帝王年号栏及明示年次；元年锚点有出处才计算。无0年，汉初十月岁首和闰月保留原样；一条末年记录不自动证明死亡。序文、月表、世次和表末追记分别判断。
- **身份**：国别、爵号、帝王、前后任及活动年与规范人物互查。同名者特别检查跨时代复用；已有简介若属于相隔数百年的另一人，不能因为同名沿用。检查活动年与时代，不只检查有明确卒年的人物。跨期不按整卷或最早一行强定单一时代。
- **参与**：不能按姓名字符串命中自动建边。“郑国”可能是国家，“某之子”中的父亲可能只是背景，同一谥号可能属于相隔数百年的两人。逐项指明这位人物在这件事里的实际身份及角色，回查原文字段和必要名字桥；同年另一个行动不自动归入现有事件。出生、去世事件的直接当事人可参加，不要求其主动行动。
- **关系**：继位或相邻格不自动证明父子、长幼或死亡。只有原文明言才建对应亲属；世表、世家和本纪有异说时分别保存来源限定的声明与待考，不擅自选择一说覆盖另一说。人物关系和参与端点都要核身份及方向。

“立”先判断即位、立储还是册封，不能一律改写为“立为继承人”；“某王元年”与前任死亡/当年继位也不是同一事实。出处必须支持这一位人物的这一行动，不能把次年继任者“薨”的格绑定到前任死亡事件；同年、同一动作类型不足以合并不同人物的事件。显式参与事件的已核年份与复用人物时代不相交时，作者预检会报疑点，必须查清身份或写出有出处的例外。

月次差别与持续时长分别表述：如“四月封、五月卒”只确定次月，不能据此推满一个月或三十日。修正规范叙述时也检查已公开旧声明，避免新增谨慎解释后仍让旧引用保留过强措辞；原始引文和两书时距异说继续保留。

先用 `history-table-review.py extract <批次> --output <批次>/table-review.json` 导出物理列；不会自动判为已校核。人审为每行填 decision/reason，表格行补完整 column_labels 和 header_basis（缺格明确说明）；为每个 item 填身份、时间或关系判断及全部出处的零基 column_indices/逐字 quote。跨格摘录补 cross_cell_reason，必要换算写有出处的 anchor_basis、era_column_basis、anchor_year、regnal_year、expected_year。更正项引用独立修订，待考项不得伪装成已纠正。

`history-table-review.py check <批次> --review <审阅文件> --output <检查结果>` 只核不可变原文/格位、逐项覆盖、作者判断是否齐备和算术一致，不证明史实正确。`history-ingest.py ready` 对有tabs的主段要求该审阅通过并绑定冻结哈希；旧批次的专项审阅另存修订目录，不重建原批次。明确错误按完整旧值守卫修订，核对人物、关系、时间、原文与画卷的实际公开结果后才结束专项验收。
