# 《资治通鉴》卷255·884年·第8—18段

接续第1—7段，连续整理卷255中和四年条余下全部十一段；不按人物筛选。涵盖舒州、鄂州与岳州、陈州解围、黄巢军王满渡败退、上源驿事变和鹿头关战事。下一段在卷256第1段，六月壬辰高仁厚奏报东川事。884年尚有卷256的21段待整理。

本批49位涉及人物（新增39位，复用10位）、25个事件、81条参与、5条养父关系、188条来源引用。段落ID和源文件行号见 [coverage.json](coverage.json) 与 [paragraphs.json](../paragraphs.json)。复用现有朱温、李克用、黄巢、李嗣源等实体，名号不拆人。原文快照SHA-256见 [manifest.json](sources/manifest.json)。

## 校核重点

- 第8段有“后月馀”“久之”等追叙。高澞任舒州、后续的舒州与庐州争战没有可靠具体年份，相关事件年份留空；不能因为段落置于884年条，就把所有追叙都标为884年。原文中的陈儒是攻舒州者。
- 第10段陈州被围“几三百日”为累计时长，只把解围归入884年。
- 第11段拆分了五月的大雨、繁台、王满渡、将领归降及后续追击。底本文字“东奔充州”与在线版本的“兗州”不一致，因此不采用“充州”定位；暂不擅改所存原文。
- 第13段将围攻上源驿、杨彦洪被射杀分开。第14段朱全忠回信否认自己知情、称朝廷使者与杨彦洪谋划，仅记录为朱全忠的辩词，不据此推翻前段叙述。
- 第15段关于李克用收养嗣源等人为追叙，建立有出处的养父关系，不填收养年份。
- 第16段鹿头关夜袭与次晨高仁厚处决杨茂言分别记录。
- 地点只采用史载名称，坐标留空；原历干支不换算公历日期。全文据仓库电子底本及[在线《资治通鉴》卷255](https://zh.wikisource.org/wiki/資治通鑑/卷255)复核，未校纸本。
