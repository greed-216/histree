# 西周画卷接缝修复

原先在前841年和前759年处把未配准的建筑、人物、船只做透明渐变，形成固定双影。修复将这两处改用一幅连续的局部画面，并保持已有年份与章节坐标。

- 使用内置 imagegen 编辑 `input.html` 渲染的1280×720局部画面，提示词见 `prompt.txt`；原始生成输出保存在 `repair-generated.png`。
- 上线候选资源：`apps/web/public/timeline-scroll/history-scroll-zhou-repaired-v2.webp`，1280×720；生效分片由现有 `scripts/build-scroll-tiles.py` 生成。
- 修补图起于原上古画布第1200px。原始前841年年度起点仍位于第1600px；春秋图裁去512px，并补偿相同的显示位移，避免把裁后图重新放回前759年。
- 旧图、旧分片和原始V6资源保留。右端使用32px边缘过渡，修补图一直覆盖到下一幅完全不透明。

验证：`pnpm test:timeline`、前端生产构建、修改的 TypeScript 文件 ESLint 均通过。补充断言验证修补图定位、裁切位移、覆盖范围以及原重影片段不再请求。浏览器以公开的时间线概览只读快照加载本地实际组件，核验前841年默认画幅、放大细节和低清/高清分片完成状态；两档均已完成。API代理因本机证书链问题未用于验收，不把快照验证当作线上验证。

状态：发布候选；本次发布检查与线上回读结果另存于本目录的发布审计文件。
